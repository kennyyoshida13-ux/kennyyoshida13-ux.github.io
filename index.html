Envio Musicas

Ferramenta pessoal de envio e agendamento de vídeos para o YouTube

O que é

Envio Musicas é um programa de uso pessoal, executado apenas no computador do seu proprietário, que envia e agenda vídeos musicais para os canais de YouTube do próprio proprietário, usando a YouTube Data API v3 oficial do Google.

O que ele faz

  • Envia vídeos de uma pasta local para os canais autorizados pelo proprietário.
  • Agenda a data e o horário de publicação de cada vídeo.
  • Mantém um registro local do que já foi enviado, para não repetir envios.

Quem usa

O aplicativo não é oferecido ao público. Ele é usado somente pelo proprietário para gerenciar os próprios canais, cujos conteúdos e direitos musicais pertencem a ele.
