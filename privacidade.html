Política de Privacidade — Envio Musicas

Última atualização: 1 de novembro de 2026

1. Sobre o aplicativo

Envio Musicas é uma ferramenta pessoal, executada exclusivamente no computador do seu proprietário, que usa os Serviços de API do YouTube (YouTube API Services) para enviar e agendar vídeos nos canais de YouTube do próprio proprietário.

2. Serviços de API do YouTube

Este aplicativo usa os Serviços de API do YouTube. Ao usá-lo, você concorda com os Termos de Serviço do YouTube. O tratamento de dados pelo Google é regido pela Política de Privacidade do Google.

3. Dados acessados

Com a autorização do titular da conta, o aplicativo acessa apenas:

  • informações básicas do canal (nome e identificador), para confirmar qual canal foi conectado;
  • permissão para enviar vídeos e definir sua data de publicação nesse canal.

O aplicativo não lê comentários, mensagens, dados de inscritos, dados financeiros nem qualquer outra informação pessoal.

4. Como os dados são usados e armazenados

  • Os tokens de autorização e o registro de envios ficam salvos apenas no computador do proprietário.
  • Nenhum dado é enviado a servidores próprios ou de terceiros, além da própria API do YouTube.
  • Nenhum dado é vendido, compartilhado, usado para publicidade ou combinado com outras fontes.
  • O aplicativo não usa cookies nem rastreamento.

5. Exclusão e revogação

O acesso pode ser revogado a qualquer momento na página de permissões da Conta Google. Os dados guardados localmente são apagados ao excluir os arquivos de autorização do computador. Para pedir a exclusão de qualquer informação, entre em contato pelo e-mail abaixo.
